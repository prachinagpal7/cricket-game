# Cricket Game 🎯🏏

Welcome to the **Browser-based Cricket Game**! 🏏

This is a **fun and interactive cricket game** built with **HTML, CSS, and JavaScript**.  
Play your own mini cricket match directly in the browser — hit the ball, score runs, and enjoy the game!

## Features
- Simple and easy-to-play cricket mechanics
- Interactive score system
- Fun browser-based gameplay without any installations
- Fully built using HTML, CSS, and JavaScript

## How to Play
1. Open `index.html` in your browser.
2. Use the on-screen controls to hit the ball.
3. Score runs and try to beat your previous high score!

## Tech Stack
- HTML5 for structure
- CSS3 for styling
- JavaScript for game logic and interactivity
